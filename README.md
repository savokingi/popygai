# Попугай — печатаем ваши идеи

Проработанный адаптивный сайт печатного центра Popygai.by. Статический HTML/CSS/JavaScript без внешних runtime-зависимостей. Шрифты, фирменные логотипы и реальные фотографии портфолио размещены локально.

Репозиторий: https://github.com/savokingi/popygai

Адрес GitHub Pages: https://savokingi.github.io/popygai/

## Запуск

Требуется Node.js 20 или новее.

```sh
npm run dev
```

Локальный адрес: http://localhost:4173

```sh
npm test
npm run build
```

Результат сборки: `dist/`, 42 заранее сгенерированные HTML-страницы с полноценным содержимым. Весь сайт работает и в корне домена, и в подпапке GitHub Pages: ресурсы используют корректную базу для каждого уровня вложенности. Прямые адреса (например, `/product/business-cards/`) доступны как отдельные страницы; после загрузки работает быстрая навигация через hash.

## Разделы

- Главная с оригинальным логотипом, настоящим попугаем и фотографиями продукции.
- Каталог: 20 изделий, 6 направлений, фильтры и поиск.
- Страницы изделий с настройками и техническими характеристиками.
- Предварительный калькулятор визиток, листовок и документов по опубликованным тарифам.
- Для бизнеса: три редактируемые подборки изделий и описание процесса.
- Портфолио: фильтры, 6 работ, подробные страницы, увеличение фотографий.
- Материалы: интерактивные образцы и отдельная подробная страница.
- Полезное: 4 полные памятки с содержанием и навигацией.
- О типографии, как заказать, цены, контакты, конфиденциальность.
- Подготовка заявки, выбор файлов, просмотр текста, копирование, скачивание, email и Telegram.
- Черновики в браузере, повторное открытие и редактирование.
- Адаптивная навигация, клавиатурное управление диалогами, reduced-motion.

## Реальные возможности и границы

**Передача заказов.** GitHub Pages обслуживает статические файлы. Поэтому сайт подготавливает заявку, а посетитель отправляет её сотруднику через действующий Telegram, email или официальную форму типографии. Сайт явно показывает, что подготовленная заявка ещё не отправлена. Никаких фиктивных номеров производственных заказов, статусов, оплаты или уведомлений.

**Файлы.** Выбор файлов добавляет их названия в описание, без передачи на сервер. Посетитель самостоятельно прикладывает исходники в выбранном канале. Предел интерфейса — 10 файлов до 25 МБ каждый. Черновик хранит только метаданные, текст и контактные сведения в localStorage; бинарные файлы не сохраняются. Принятый типографией заказ отслеживается на существующем официальном сайте.

**Цены.** Исходные тарифы проверены 22.10.2026 по https://popygai.by/services/all. Визитки рассчитываются комплектами по 96 шт., листовки — по 100 шт., документы — по физическим листам. Комплекты суммируются без предположений о скидках. Дизайн, дополнительная обработка, доставка и сроки подтверждаются отдельно. Для прочих изделий — индивидуальная заявка. Весь тарифный код — `calculatePrice()` в `data.js`.

**Контент.** Источники и размеры фотографий записаны в `assets/asset-manifest.json`. Тиражи, отзывы, сроки выполнения конкретных работ и личности сотрудников не выдуманы. Фотографии в портфолио показывают реальные опубликованные работы; параметры, которые не были опубликованы, не приписываются этим работам. Фактурные образцы — иллюстрации интерфейса, не гарантии цветопередачи.

## Публикация на GitHub Pages

В `.github/workflows/pages.yml` подготовлена сборка, тесты и публикация. Нужно разместить проект в выбранном репозитории GitHub с веткой `main` и выбрать **Settings → Pages → Source → GitHub Actions**. Workflow запускается по push или вручную. Домен и DNS в этом проекте не изменялись. Sites/chatgpt.site не используются.

Для производственной приёмки заказов в самом интерфейсе потребуется отдельно подключить серверную обработку файлов и уведомления типографии, а также согласовать актуальные тарифы и данные с компанией. Секреты нельзя размещать в статическом коде.

## Устройство

- `index.html` — оболочка и метаданные.
- `styles.css` — дизайн, адаптивность и анимации.
- `app.js` — страницы, маршрутизация и интерактивность.
- `data.js` — услуги, контент, контакты и тарифы.
- `assets/` — оригинальная айдентика, оптимизированные WebP и локальные шрифты.
- `scripts/` — локальный сервер и сборка.
- `tests/` — проверка расчётов и целостности данных.

Шрифт Manrope распространяется по SIL Open Font License: `assets/fonts/OFL.txt`.

Исходные JPG/PNG из папки фотографий и исследовательские материалы не попадают в сборку. В ней используются оптимизированные WebP, SVG и локальные шрифты.
